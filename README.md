# 🎮 Decifra.IA — Missão IA: Escape do Sistema

## 📖 Sobre o projeto

O **Decifra.IA** é um jogo educativo executado diretamente no **terminal**, criado para ensinar conceitos básicos sobre Inteligência Artificial de forma simples e interativa.

No jogo, o jogador fica preso dentro de um sistema controlado por uma IA chamada **NEXUS**. Para escapar, é necessário explorar diferentes fases, encontrar pistas, interagir com computadores e coletar chaves.

Durante a aventura, são abordados temas como:

- 🧠 Alucinações e informações falsas geradas por IA;
- 🔐 Privacidade e proteção de dados;
- ⚖️ Viés e decisões automatizadas;
- 🤖 Uso consciente e crítico da Inteligência Artificial.

## 🎯 Objetivo

Encontrar as três chaves de segurança e utilizá-las para abrir a porta de saída:

- 🔑 Chave da Verdade
- 🔑 Chave da Privacidade
- 🔑 Chave da Justiça

## 🕹️ Como jogar

O jogador explora os mapas utilizando o teclado.

| Tecla | Ação |
|---|---|
| `W` | Mover para cima |
| `A` | Mover para esquerda |
| `S` | Mover para baixo |
| `D` | Mover para direita |
| `E` | Interagir |
| `Q` | Sair |

## 🗺️ Fases

### 🧠 Fase 1 — Central da Verdade

O jogador deve explorar a área, encontrar uma pista e investigar os computadores para descobrir qual deles está apresentando informações incorretas.

Ao corrigir o problema, recebe a **Chave da Verdade**.

### 🔐 Fase 2 — Setor de Privacidade

O jogador precisa explorar o ambiente e encontrar o código necessário para continuar, evitando acessar informações pessoais desnecessárias.

Ao concluir a missão, recebe a **Chave da Privacidade**.

### ⚖️ Fase 3 — Núcleo da Justiça

O jogador encontra uma pista e investiga os computadores para descobrir uma informação inadequada utilizada pelo sistema de decisões.

Após corrigir o problema, recebe a **Chave da Justiça**.

### 🚪 Fase Final — Escape

Com as três chaves em mãos, o jogador consegue abrir a porta final e escapar do sistema NEXUS.

## 📊 Pontuação

O jogador recebe pontos ao:

- Encontrar pistas;
- Corrigir problemas;
- Encontrar chaves;
- Concluir as fases.

A pontuação final é apresentada ao terminar o jogo.
